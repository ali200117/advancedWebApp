# DAT152 – eksamenstrening

Øvingsside for DAT152 Advanced Web Applications.

- **Eksamener:** tidligere eksamener og øvingseksamener i samme format, med svarfelt for hver deloppgave. Svarene lagres i nettleseren og kan lastes ned som tekstfil.
- **Teorispørsmål:** skriv svaret ditt og sammenlign med løsningsforslaget.
- **Pugg:** korte forklaringer med eksempler.

Åpne `index.html` i nettleseren. Ingen installasjon trengs.
